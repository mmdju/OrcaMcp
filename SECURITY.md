# Security Policy

Orca MCP is a read-only public service. There is nothing to log in to and no user data is stored.

- All 12 tools are read-only. No tool can change, delete or publish anything.
- No API keys are needed to use the hosted endpoint.
- Upstream provider keys live server-side and are never exposed in responses.
- Abuse (scraping, flooding) gets rate-limited.

Found a security issue? Open a GitHub issue and we will look at it.
