# اورکا MCP - هوش فیلم و سریال برای ایجنت‌ها

یه MCP سرور عمومی که به ایجنت‌های هوش مصنوعی دانش واقعی فیلم و سریال میده: جستجو، نمره‌ها از چند منبع، رتبه IMDb Top 250 و Letterboxd Top 500، کجا ببینم، قسمت‌ها، آرتوورک. فقط خواندنی، بدون کلید.

**آدرس زنده:** `https://orca-mcp.mmdju.workers.dev/mcp`

## اتصال در ۳۰ ثانیه

تو OpenCode (`opencode.jsonc`):

```json
{
  "mcp": {
    "orca-mcp": {
      "type": "remote",
      "url": "https://orca-mcp.mmdju.workers.dev/mcp",
      "enabled": true
    }
  }
}
```

بعدش فارسی حرف بزن: «رتبه پدرخوانده تو IMDb چنده؟»، «یه اکشن خوب بعد ۲۰۲۲ بگو»، «ترتیب دیدن گادفادر چیه؟»

## ۱۲ ابزار

جستجو، جزئیات، فیلتری (ژانر/سال/نمره)، ترند روز، کجا ببینم، مقایسه رتبه‌ها، مقایسه نمره‌ها، ترتیب فرنچایز، مشابه‌ها، کارنامه بازیگر، آرتوورک، قسمت‌های سریال.

نکته: فارسی هم می‌فهمه (`language: fa-IR`) - اسم و خلاصه فارسی هرجا موجود باشه.
